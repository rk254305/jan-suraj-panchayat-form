# जन सुराज | मिशन पंचायती राज चुनाव - 2027
## प्रत्याशी आवेदन वेब एप्लिकेशन (Candidate Application Web App)

यह वेब एप्लिकेशन बिहार पंचायती राज चुनाव 2027 के लिए जन सुराज के तहत विभिन्न पदों (मुखिया, सरपंच, जिला परिषद सदस्य, पंचायत समिति सदस्य, वार्ड सदस्य एवं पंच) के संभावित प्रत्याशियों के आवेदन प्राप्त करने, व्यवस्थित करने और Google Sheets से रियल-टाइम सिंक करने हेतु तैयार किया गया है।

---

### 🌟 मुख्य विशेषताएं (Key Features)

1. **आधिकारिक जन सुराज ब्रांडिंग:**
   - शीर्ष पर जन सुराज का आधिकारिक बैनर एवं प्रशांत किशोर जी का प्रेरक विचार।
   - मोबाइल-फ्रेंडली Google Forms कार्ड स्टाइल लेआउट।
2. **सटीक एवं गतिशील प्रश्न (Dynamic Form Logic):**
   - **जिला परिषद सदस्य चयन पर:** क्षेत्र संख्या (1 से 75) का ड्रॉपडाउन स्वतः प्रकट होता है।
   - **पूर्व चुनाव अनुभव 'हाँ' होने पर:** पूर्व लड़े गए पद का विकल्प स्वतः एक्टिव होता है।
   - **महिला चयन पर:** 8वीं पास योग्यता का विशेष निर्देश।
   - **बिहार 38 जिले एवं 534 प्रखंड:** जिला चुनते ही केवल उसी जिले के प्रखंड ड्रॉपडाउन में आते हैं।
   - **243 विधानसभा क्षेत्र:** सर्च एवं ऑटो-सुझाव युक्त इनपुट।
3. **Google Sheets रियल-टाइम सिंक:**
   - Google Apps Script Webhook के ज़रिए प्रत्येक आवेदन सीधे आपकी Google Sheet में तत्काल दर्ज हो जाता है।
4. **ऑफलाइन बैकअप एवं स्थानीय सुरक्षा:**
   - यदि इंटरनेट धीमा हो या नेटवर्क कट जाए, तो भी डेटा `localStorage` में तुरंत बैकअप हो जाता है।
5. **एडमिन पैनल (`admin.html`):**
   - सभी आवेदनों को देखने, पद एवं जिला अनुसार फ़िल्टर करने तथा 1-क्लिक में **Excel / CSV एक्सपोर्ट** करने की सुविधा।
6. **व्हाट्सएप शेयरिंग एवं रसीद प्रिंटिंग:**
   - आवेदन सफल होने पर यूनिक रेफरेंस आईडी (`JS-PR-2027-XXXXXX`) जनरेट होती है तथा व्हाट्सएप शेयरिंग एवं प्रिंट पावती रसीद उपलब्ध होती है।

### 📋 Google Sheets से कैसे जोड़ें (How to Connect Google Sheet)

1. अपनी Google Drive में एक नई **Google Sheet** बनाएं।
2. शीट के मेनू में जाकर **Extensions > Apps Script** पर क्लिक करें।
3. एडिटर में पहले से मौजूद कोड को मिटा दें और इस प्रोजेक्ट की फ़ाइल **`google_apps_script.gs`** का पूरा कोड वहाँ पेस्ट कर दें।
4. ऊपर **Save (Ctrl + S)** करें।
5. ऊपर दाईं ओर **Deploy > New deployment** पर क्लिक करें।
6. **Gear icon (Select type)** पर क्लिक करके **Web app** चुनें।
   - **Description:** `Jan Suraaj Form Sync`
   - **Execute as:** `Me (आपकी ईमेल आईडी)`
   - **Who has access:** `Anyone` *(यह सबसे आवश्यक है ताकि पब्लिक फॉर्म डेटा भेज सके)*
7. **Deploy** पर क्लिक करें और Google द्वारा मांगी गई अनुमतियों (Permissions) को Authorize करें।
8. आपको एक **Web App URL** प्राप्त होगा (उदा. `https://script.google.com/macros/s/.../exec`)।
9. इस URL को वेब ऐप के शीर्ष पर दिए गए **⚙️ शीट लिंक** बटन में पेस्ट करके सेव कर दें (या `config.js` फ़ाइल में पेस्ट कर दें)।

### 🚀 Vercel पर लाइव डिप्लॉयमेंट (Vercel Deployment)

यह प्रोजेक्ट 100% Vercel-रेडी है (`vercel.json` सम्मिलित है)।

#### विकल्प 1: GitHub के ज़रिए (अनुशंसित - ऑटोमैटिक)
1. अपने GitHub रिपॉजिटरी में कोड पुश करें।
2. [Vercel Dashboard](https://vercel.com/dashboard) में जाएं।
3. **Add New... > Project** पर क्लिक करें और इस GitHub रिपॉजिटरी को चुनें।
4. **Deploy** पर क्लिक करें। 10 सेकंड में आपकी साइट लाइव हो जाएगी!

#### विकल्प 2: Vercel CLI द्वारा
```bash
vercel login
vercel --prod
```
